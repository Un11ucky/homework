# Блок 1. Типы данных и работа со значениями

* имя пользователя

# Блок 2. Методы строк и преобразование типов

## Задача 3 — Профиль пользователя v2

### Дано

```js
let userName = '   aNNa   '
let age = '19'
let city = 'berlin'
let isStudent = true
let hobby
let pet = null
```

### Что нужно сделать

#### 1. Подготовить имя

Из:

```js
'   aNNa   '
```

получить:

```js
'Anna'
```

#### 2. Превратить возраст в число

Из:

```js
'19'
```

получить:

```js
19
```

#### 3. Сделать город красивым

Из:

```js
'berlin'
```

получить:

```js
'Berlin'
```

#### 4. Вывести результат

Пример:

```js
Имя: Anna
Возраст: 19
Через 5 лет: 24
Город: Berlin
Студент: true
Хобби: undefined
Питомец: null
```

### Подсказки

Можно использовать:

* `.trim()`
* `.toLowerCase()`
* `.toUpperCase()`
* `.slice()`
* `Number()`

# Блок 4. Условия `if / else`

## Задача 8 — Проверка возраста

### Цель

Сделать первое условие в JS.

### Дано

```js
let age = 17
```

### Что нужно сделать

Если возраст **18 или больше**, вывести:

```js
Доступ разрешён
```

Иначе:

```js
Доступ запрещён
```

---

## Задача 9 — Проверка логина

### Дано

```js
let login = '   Admin   '
```

### Что нужно сделать

1. Убери лишние пробелы
2. Приведи строку к нижнему регистру
3. Если логин равен `admin`, выведи:

```js
Привет, админ
```

Иначе:

```js

```

## Задача 10 — Мини-проверка профиля

### Цель

Объединить строки, числа, сравнения и `if / else`.

### Дано

```js
let userName = '   max   '
let age = '16'
let isStudent = true
```

### Что нужно сделать

#### 1. Подготовь имя

Из:

```js
'   max   '
```

сделай:

```js
'Max'
```

#### 2. Возраст сделай числом

#### 3. Выведи сообщение

Если человеку **18+**, вывести:

```js
Max, доступ разрешён
```

Иначе:

```js
Max, партия тобой недовольна
```

#### 4. Дополнительно

Если `isStudent === true`, выведи ещё:

```js
Ты студент
```
